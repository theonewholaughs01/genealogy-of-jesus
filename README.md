# The Genealogy of Jesus Christ — Interactive Study

An accessible, single-page study experience centered on the genealogy in **Matthew 1:1–17**. The visual design uses the original dark parchment-and-gold direction, with search, a timeline, study cards, modal reading, and a quiz.

## Scope and accuracy

The primary sequence follows Matthew 1:1–17 and presents Matthew’s three fourteen-generation sections. The guide also links Luke 3:23–38 as a distinct genealogy, noting that Luke follows David through Nathan whereas Matthew follows Solomon. Interpretations that seek to reconcile the two lists are described as interpretations rather than established fact.

Date labels are broad educational estimates; the biblical text does not supply dates for every person. The project aims to distinguish the explicit biblical text from later tradition and devotional reflection.

## Features

The page provides name and reference search, era filters, keyboard-operable study cards and modal navigation, reduced-motion support, visible focus states, a skip link, source notes, contextual cards for the women associated with Matthew’s genealogy, and a self-contained quiz.

## Run locally

Open `genealogy_interactive.html` in a modern browser. No build step, framework, or server is required.
